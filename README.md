# TecnoMovil Data

## EA2 - Programacion Orientada a Objetos II

Institucion Universitaria Digital de Antioquia

## Descripcion
Sistema de procesamiento funcional de datos simulados
para la gestion del transporte urbano.

## Funcionalidades
1. Afluencia por estacion.
2. Identificacion de horas pico.
3. Rutas mas utilizadas.
4. Patrones de viaje por usuario.
5. Calculo de tiempo promedio entre estaciones.
6. Deteccion de sobrecarga simulada.

## Tecnologias
Java, Streams, lambdas, funciones puras y colecciones inmutables.

## Compilar
javac src/*.java

## Ejecutar
java -cp src Main

## Datos
10000 registros simulados.
